**Source file**: `color-palette.jpg`

## Palette Values (Applied)

| Role | Hex | Usage |
|------|-----|-------|
| Base dark | `#1B1B1D` | Body background, modal backgrounds |
| Warm dark | `#3D332F` | Glass panels, cards, sidebar |
| Orange accent | `#FF8A3D` | Buttons, FAB, active states, icons |
| Light peach | `#FFCF9A` | Secondary accent, medium priority |
| Cream text | `#FFF6EC` | All text, headings, labels |
